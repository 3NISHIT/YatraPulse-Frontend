## About YatraPulse

YatraPulse is a web application for discovering travel experiences and planning journeys.

This repository contains the React frontend of the YatraPulse platform, built using React and Vite.

## Project Repositories

| Component | Technology | Repository |
|---|---|---|
| Frontend | React + Vite | [YatraPulse-Frontend](https://github.com/3NISHIT/YatraPulse-Frontend) |
| Backend | Laravel API | [YatraPulse-Backend](https://github.com/3NISHIT/YatraPulse-Backend) |

## Getting Started

### Prerequisites

- Node.js
- npm

### 1. Clone the repository

```bash
git clone https://github.com/3NISHIT/YatraPulse-Frontend.git
cd YatraPulse-Frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure Environment

If the application requires environment-specific settings, create a local `.env` file using the project's `.env.example`, if available.

Do not commit passwords, API keys, or private credentials.

### 4. Start Development Server

```bash
npm run dev
```

### 5. Create Production Build

```bash
npm run build
```
